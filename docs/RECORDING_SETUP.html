全身動作拍攝環境說明

適用 ZED MINI 單機錄製與本專案 OpenSim 轉換。以下距離是現場測試起點，需以全身入鏡與骨架穩定度調整，並非官方保證的全身動作精度。

先從 2.5～3 公尺開始

從相機到受測者軀幹約 2.5～3 m 開始測，讓頭頂、雙腳與伸開的手都有餘裕；整個動作中留約 10～15% 畫面邊界。若靠近後腳被裁掉，就增加距離；若退太遠骨架太小，就縮小動作範圍或調整場地。不要為了硬塞全身而把相機大幅向上／向下斜拍。

這是依全身取景與深度誤差的實務起點，不是 ZED MINI 的最近對焦／最短深度距離。官方相機深度範圍也不是可靠全身追蹤範圍；距離增加會降低深度精度。身高、拍攝模式與相機實際校正視角會影響需要的距離。

固定、水平相機← 2.5～3 m →受測者／止滑墊← 約 1 m →安靜背景

相機先放在接近腰部、約 0.8～1.0 m 的穩固腳架上，橫放保持水平，再以全身入鏡檢查調整。這個高度只是起點，不同身高與視角需要現場調整；移動或轉動相機後重做靜態校正。

地面、背景與光線

  • 地面：選硬質平面，鋪平整、固定、不反光、有細節紋理的止滑墊。墊子要覆蓋整個步伐範圍；避免白亮磁磚、鏡面、玻璃。不要站在床墊、棉被或會壓縮的軟面上測站立／深蹲。
  • 背景：不需要綠幕；避免鏡子、玻璃、其他人走動與強烈背光。可用有適度圖案的霧面布或室內固定物提供紋理，且不要遮到腳或與衣服融在一起。人體後方先留約 1 m 淨空作場地安排起點，並非 SDK 硬性最低值；不夠時先看遮擋與影像品質。
  • 光線：均勻穩定，讓腳趾、腳跟與褲子邊界可見；避開窗戶直射、暗房、強陰影與閃爍光源。不要只因彩色畫面看得見就認定深度有效。
  • 衣物：鞋襪、褲子與地面有對比；避免很寬鬆或遮住腳踝的衣物、亮面鞋。若測試允許，可先比較霧面鞋與原穿著；不能宣稱換鞋必定改善。不要將 SDK 腳趾點視為解剖級足部量測。
  • 畫面：只留一名受測者，避免兩腿重疊、手貼軀幹、快速轉到整條腿被遮住。需要測轉身、交叉步或快速動作時，單視角本來就可能不穩，需在備註標示。

每次先做短錄製對照

  1. 關閉 Depth Viewer 再啟動主程式，記下 EXE 檔名、版本／SHA-256、SDK 與顯示卡。先檢查彩色與深度；不要同時讓兩個程式占用相機。
  2. 站穩後靜態錄約 5 秒，腳掌平放、雙腿不要互相遮擋。畫面有完整骨架才算開始；程式只判完整點，未自動證明站姿靜止。
  3. 做一段約 10 秒不動站姿，再做慢速淺蹲、左右各抬腿的短片。先確認基本動作，再增加速度與深度；一次只改距離、墊子或光線的一項，才知道影響來源。
  4. 用同一時間點比較 MP4、TRC marker 與 MOT 模型：TRC 已跳動→先查深度、遮擋、補點；TRC 平順但模型突然跳→查 IK、模型配對、角度連續與後處理。單看一張 OpenSim 圖不能確定原因。
  5. TRC 可能已裁頭尾但時間沒有歸零，MP4 沒同步剪短；請依原錄製時間比較。模型需使用該工作階段的 OSIM，勿混用 candidate 或其他人的模型。

若已失敗，記下抽動的秒數與左右腳，保留該次 MP4、TRC、MOT、OSIM 與 notes。source-quality-20261106 正常結束會先將原始 TRC、逐幀骨架與結果 JSON 保存在工作階段 diagnostics，再清理 .studio；舊 EXE 尚無此行為。請一起保留 diagnostics，便於深查。

角度限制如何幫忙

本專案模板已有膝 0–140°、踝 ±50° 等限制。它能限制求解器找解的範圍，無法排除範圍內的一幀抽動，也無法保證後續直接改寫 MOT 仍符合模型。模型數字不是你的個人關節活動正常值。

合理改善流程是：先檢查逐點信心、骨長和時間突波 → 對可靠短缺口補點 → 讓 IK 使用實際模型限制 → 檢查最終 MOT 範圍、連續性與 marker 殘差。不能只把超出角度刪掉，也不能強制所有影格站直；這可能改掉真正的深蹲、跳躍或彎腰。

來源與適用限制

  • StereoLabs 深度距離／誤差說明；低紋理與反光影響。
  • 骨架信心、擬合與平滑設定；OpenSim 範圍約束原理。
  • 查閱日期 2026-11-06。2.5～3 m、相機高度、後方淨空及邊界比例為本文件的現場試拍建議，尚未在測試者場地驗證。現有 SDK 5.4.1，無相機；不能保證其他電腦的 5.5 相容性或抽動已排除。
